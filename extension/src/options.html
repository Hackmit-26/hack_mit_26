Shop Wrapped Extension settings

Backend

Port 8080 in real mode, 8081 in the fast demo mode. Anything that isn't localhost needs a one-off Chrome permission, which this page will ask for.

Sign in as

The backend's dev auth takes a user id and sends it as Bearer dev:<id>.

Defaults

Quick save is ⌘⇧U (Ctrl+Shift+U elsewhere). Rebind it at chrome://extensions/shortcuts.
